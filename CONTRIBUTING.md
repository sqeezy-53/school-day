# Участие в разработке

Если хотите помочь с развитием «Школьного дня», буду рад любой помощи!

Можно сообщать об ошибках, предлагать идеи, тестировать программу или улучшать код.

## Как внести изменения

1. Сделайте Fork репозитория.
2. Внесите изменения.
3. Проверьте, что всё работает.
4. Отправьте Pull Request с описанием изменений.

Перед отправкой желательно проверить код:

```sh
cargo fmt --all -- --check
cargo clippy
cargo test
```

Если планируете крупные изменения, лучше сначала обсудить их в Issues или Discussions.
