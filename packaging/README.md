# Сборка Flatpak

Пакет предназначен для GitHub Releases. Заявка во Flathub не создаётся.

Нужны Flatpak, Python 3.11 или новее и Cargo. Сборщик, GNOME SDK 51 и Rust загружаются автоматически. Для окружения и сборки потребуется несколько гигабайт свободного места.

Скрипт использует системный `flatpak-builder`, если он установлен. Иначе пробует сборщик из пакета `org.flatpak.Builder`. Если его библиотеки несовместимы с системой, потребуется установить `flatpak-builder` через менеджер пакетов дистрибутива.

Из корня проекта:

```sh
python packaging/build-flatpak.py \
  --work-dir /mnt/gamedisk/school-day-build \
  --output-dir /mnt/gamedisk/school-day-release/v0.1.0
```

Скрипт собирает текущие исходники, включая незакоммиченные изменения. Личные файлы из `data` в пакет не попадают. Зависимости Cargo включаются в архив исходников; сама сборка Cargo выполняется без сети.

Результат: `.flatpak`, архив исходников с зависимостями, значок и `SHA256SUMS`.

В каталоге сборки находятся кэш, SDK и отдельная пользовательская установка Flatpak. Системные приложения Flatpak не изменяются.

## Перед публикацией

Закоммитьте проверенные исходники. Подготовьте тег `v0.1.0` на этом коммите и приложите пакет, архив исходников и контрольные суммы к GitHub Release. Не публикуйте сборки с личными данными.

`SOURCE.json` фиксирует исходный коммит и хеши файлов сборки. Если собирали до коммита, в нём будет `working_tree_dirty: true`. Для релиза с точной привязкой к тегу повторите сборку после коммита.

Лицензия приложения пока не выбрана, поэтому в метаданных стоит `LicenseRef-proprietary`. Открытую лицензию следует выбирать отдельно.

Манифест и часть кода подготовлены с помощью ИИ. Этот манифест не предназначен для подачи во Flathub: у каталога есть отдельные требования к таким материалам.
