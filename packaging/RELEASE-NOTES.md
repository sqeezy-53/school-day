# Школьный день 0.1.0

Первая версия. Расписание уроков, домашние задания и настройка звонков.

**Windows x64:** скачайте установщик `.exe`. Все библиотеки включены.

**Linux x86_64:** установите Flatpak и выполните:

```sh
flatpak install --user ./school-day-0.1.0-x86_64.flatpak
flatpak run io.github.sqeezy_53.school-day
```

Проверено на Linux и Windows 11. Windows 10 отдельно не проверялась. Установщик Windows без цифровой подписи.
