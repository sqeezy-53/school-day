# Школьный день 0.2.0

- Добавлены подсказки предметов и кабинетов. Выбирать можно стрелками и Enter или мышью.
- Добавлено подтверждение удаления уроков и домашних заданий.
- Исправлена потеря данных при запуске нескольких копий приложения.
- Исправлены ошибки сохранения данных и выбора темы.
- Длинные названия и домашние задания больше не растягивают окно.

**Windows x64:** скачайте установщик `.exe`. Все библиотеки включены.

**Linux x86_64:** установите Flatpak и выполните:

```sh
flatpak install --user ./school-day-0.2.0-x86_64.flatpak
flatpak run io.github.sqeezy_53.school-day
```

Установщик Windows без цифровой подписи.
