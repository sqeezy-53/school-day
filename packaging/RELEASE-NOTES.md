# Школьный день 0.3.0

Появилось интерактивное обучение. В нём можно добавить урок, записать домашнее задание и отметить его выполненным. Учебные записи исчезают после выхода. Повторить обучение можно из настроек.

- Интерфейс подстраивается под узкие окна.
- Исправлены ошибки при сохранении настроек и подборе времени уроков.
- Деинсталлятор Windows сохраняет посторонние файлы в папке установки.
