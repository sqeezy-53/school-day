# Перенос данных

Desktop и Android читают один JSON-документ. Поле format_version равно 1. Документ содержит уроки, отдельные задания, настройки конкретных дат и необязательное расписание звонков. Тема, подтверждения, уведомления и идентификатор устройства хранятся локально.

У урока и задания разные UUID. При прикреплении отдельного ДЗ его UUID переходит в homework_id урока. Проверка на входе отвергает пересечения идентификаторов, неизвестную версию, некорректные звонки и перекрывающиеся уроки. Обе формы JSON из 0.6.2 принимаются с созданием UUID. Desktop перед записью нового формата сохраняет исходный файл в каталоге backups.

Локальный импорт целиком заменяет расписание после проверки, предварительного просмотра и защитной копии. При отсутствии звонков в импортируемом расписании Desktop сохраняет свои звонки. Выгруженный с устройства файл содержит школьные данные в открытом виде.

Для будущего обмена Changes::between сравнивает две версии одной базы. Удаление определяется по UUID, присутствовавшему в сохранённой общей версии и отсутствующему в новой. Функция conflicts сравнивает два набора изменений с общей версией и находит расходящиеся правки, включая удаление с одной стороны и редактирование с другой. Без общей версии импорт выполняет только явную замену. Сетевой обмен и автоматическое слияние относятся к следующему этапу.
